# ETF 市價漲跌幅排行榜

## 範圍與口徑

新增「報酬排行榜」檢視，提供日、近一週、近一月，以及正負各前 10 名、只看正榜、只看負榜。依使用者確認，只比較市價漲跌幅，不使用含息報酬。沿用深淺色模式與搜尋、類型、投信、除息及折溢價篩選；點選長條可開啟原有 ETF 詳情。

- 日：`change_pct`，相對前一交易日收盤。
- 週／月：`returns.price["1w"]`／`returns.price["1m"]`。基準日與期末日顯示於圖表上方；是滾動區間，不是本週或本月累計。
- 歷史市價採現有 Yahoo 分割還原日線，期末為本站查核後收盤價；價格資料與基金公告資料的出處不同。
- 有效市價須為有限正數；報酬須為有限數字。缺資料、字串、無限值不列入，持平不列正負榜。
- 正榜由高到低，負榜由最負到較負；同值按代號排序。未滿 10 檔不補位。
- 正負榜採共同絕對值比例尺，顯示正負號。不同商品類型、交易幣別未正規化，使用者可縮小篩選範圍。
- 不新增資料抓取、AI API、圖表套件或建置流程；未修改機器人維護的歷史資料與 latest.json。

零 Token 是依本專案架構的判斷：報價取得、排序與繪圖由一般程式執行，沒有模型呼叫。Codex 開發／維護對話仍使用帳戶用量；未來若另接模型 API，依該 API 計費。[OpenAI API 計費說明](https://developers.openai.com/api/docs/pricing)

報價刷新頻率與來源延遲不同：每分鐘刷新延遲行情，不會變成即時行情。正式淨值、持股與規模仍按投信／公會公告更新，須分別標示日期。

公開網站可免費瀏覽行情，不代表可任意轉送到另一個網站。證交所 FAQ 說明，傳輸或加值後提供他人使用需經同意並簽約，資訊商產品價格由資訊商訂定。[證交所資訊使用 FAQ](https://www.twse.com.tw/zh/products/information/qa.html)

證交所直接授權表列有非券商傳輸授權費每月新臺幣 60,000 元、網際網路自動更新 0～5,000 人級距每月 100,000 元等項目；這些是特定授權項目，**不是本網站已取得的報價或預估月費**。資訊商方案、延遲行情條件與櫃買授權需另確認。[證交所即時交易資訊費率](https://www.twse.com.tw/zh/products/information/real-time.html)

GitHub Actions 排程最短五分鐘且可能延遲；現有完整資料抓取與發布流程不適合作為分鐘級行情後端。[GitHub 排程說明](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#schedule)

建議若要盤中更新，先取得允許公開展示且覆蓋上市／上櫃 ETF 的 API 方案，再用中央快取供所有訪客共用，避免每位訪客直接打供應商。休市停止抓取、背景分頁暫停刷新、過期資料明示時間，金鑰放在後端。一次建置後可自動運行，資料源改版、授權與主機成本仍需維護。
