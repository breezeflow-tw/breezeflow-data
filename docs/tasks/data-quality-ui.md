# 資料完整度與逐週缺漏說明

依擁有者確認的優先順序，先讓現有資料的日期、來源與缺漏可以辨認，再由資料端補官方歷史。這一輪只改網站與獨立前端測試，不改投信抓取、數據或週申贖公式。

## 網站行為

- 篩選列下方新增可展開的「資料完整度」。依目前搜尋、類型、投信等篩選，統計淨值、規模、單位數及前十大成分的有值檔數、數值／日期／來源齊備檔數，以及本週、近四週可估算檔數。
- 月公告單列，較早的日公告單列；不自行訂過期天數，也不將「欄位齊備」宣稱為「最新、正確」。無效或晚於行情日的日期不計入齊備檔數。
- 個別 ETF 的來源註記說明日期狀態。淨值沒有公告日期時顯示待確認，不再用行情日補成淨值公告日。
- 週資金流可展開最多四週的起訖日、比較期初、淨申購估算與後端提供的缺漏原因。零值仍是零；缺值保留「—」。未提供可計算週數時顯示待確認。
- 不新增重複的財務欄位，不修改原始來源連結白名單及既有篩選、排名口徑。
