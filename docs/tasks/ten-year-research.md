# 十年歷史資料、K 線及投入模擬

2026-10-23 擁有者確認：以近十年為基礎；上市未滿十年從上市日起；二十年保留擴充能力。

## 目前狀態與資料界線

- 官方每日價量已有 2026-10-19 起的逐筆來源紀錄，並非完整十年。以實際資料及報告為準。
- 沒有已核實取得方式及公開使用範圍的十年歷史包；不自動抓一般歷史查詢頁，不把目前 Yahoo 區間報酬的資料改標成官方歷史。
- 實作跨 `scripts/`、`tests/`、`web/index.html`、發布流程：每日保存、離線匯入、完整度檢查、K 線與回測共用同一份資料。
- 十年是輸出及查詢目標，不是刪除期限。CSV 保留所有已取得歷史；`export(..., years=20)` 可供日後擴充。
- 停牌／休市與缺資料必須有交易日證據；完整公司行動涵蓋「該段確定沒有事件」。現有 `dividend` 表缺少逐段完整性證據，不直接解鎖回測。

## 保存及發布

原本 `exchange_daily` 繼續保存兩市場 OpenAPI 原值。新資料表：

| 表 | 用途 |
| --- | --- |
| research_source | 官方出處、取得與公開利用證據、查核人與日期、幣別 |
| research_price | 回補的未還原開高低收、成交單位數，逐筆來源 |
| research_action | 除息日、每單位配息、實際發放日；分割生效日與新／舊單位比例 |
| research_coverage | 指定 ETF 與區間的完整交易日清單或公司行動完整性證據 |
| research_import | 資料包 SHA-256 與匯入時間，防止重複執行 |

`store.py` 依日期保存價量 CSV；其他表固定排序保存。發布時 `release.py manifest` 由最終已提交的 CSV 重建 SQLite、每檔研究 JSON 及索引。每檔 JSON 檔名有內容雜湊，前端檢查資料日期，防止不同發布版本混用。首頁不下載全部歷史；點選 ETF 詳情的「載入歷史行情與回測條件」才下載該檔。

## 離線資料包（不得拿測試資料發布）

資料包放在 `data/research-imports/*.json`，由 PR 審查原始官方出處與授權證據，合併後每日機器人匯入。`status: verified` 是審查結果，不是寫上字串就自動取得法律授權。若只取得個人使用權，不得放入公開儲存庫。

一個來源一包，必要時價格、事件與日曆分成不同包。結構：

```json
{
  "version": 1,
  "source": {
    "id": "經核實的唯一來源版本 ID",
    "provider": "官方提供機構",
    "dataset": "資料集與版本",
    "url": "https://官方原始資料網址",
    "license": "已核實的公開使用條件",
    "acquisition_evidence": "https://取得方式的官方證據",
    "redistribution_evidence": "https://公開再利用的官方證據",
    "checked_at": "2026-10-23",
    "reviewed_by": "實際查核者",
    "status": "verified",
    "currency": "TWD"
  },
  "prices": [],
  "actions": [],
  "coverage": []
}
```

- `prices`：`code,date,market,open,high,low,close,volume`；volume 是受益權單位，不能用張數。只收原始市價，不收含息還原價或淨值。
- `actions`：`code,date,kind`。`dividend` 必須有 `cash,pay_date`；`split` 必須有 `ratio`（新單位／舊單位）。其他事件不支援，不應把該段標成已完整。
- `coverage`：`code,kind,start,end,complete:true`。`calendar` 附區間全部 `trading_days`；`actions` 表示區間內所有配息、分割及其他會影響模擬的事件已核對、全部可正確處理；有不支援事件不得核實。
- 主鍵重複、非有限數值、不合理開高低收、未來日期、來源證據缺漏、既有數值衝突：整包拒絕，不部分匯入。更正另案明確核對，不無聲覆蓋。
- 本機驗證只能寫暫存目錄；不要手動提交 `data/history` 或 `web/data/latest.json`。

## 計算與 UI

- 日 K、週 K、月 K、成交量及日線 MA20／MA60；最多顯示最近 120 根，缺資料及未核實日曆不彙整完整週月。均線跨分割暫停顯示。原始市價明示未還原。
- 單筆、每月定時定額、單筆加每月追加；每月日期 1～31，月底不足則取月底，休市順延。超出結束日不扣款。
- 使用當日收盤價、整數單位；同日投入合併，零頭留現金。費率與最低手續費由使用者設定，預設 0 明示未計。未扣期末賣出費稅、個人所得稅、滑價。
- 除息日開盤前既有單位取得領息權，當日新買單位不取得；發放日入現金，選再投入者於可交易日買入。尚未發放者列應收配息，不重複計入報酬。
- 分割改單位數，保留原價量；同日多公司行動、反分割涉及畸零單位尚不支援，計算時攔截。
- 總資產＝市值＋現金＋應收配息。年化採 XIRR，未滿一年不顯示年化。兩種投入方法需相同資金可用條件才適合比較；第一版不做誰勝出的推薦。
- 上市日期、幣別、交易日曆、價格、公司行動及覆蓋證據完整才計算；缺資料不能靠縮短期間冒充十年回測。

## 尚待外部資料解決的工作

1. 取得兩市場十年歷史價量的允許取得方式與公開再利用證據／正式資料包。
2. 各投信同期間配息、分割及沒有其他事件的完整證據；不能以最近一次公告推定十年完整。
3. 歷史交易日含颱風等臨時休市、停牌及上市前後邊界。
4. 資料核實後按 ETF／年份分批匯入，檢查缺口、抽核來源，再開放對應區間。

資料未到齊時，程式可驗證、K 線可呈現已取得期間，但不得宣稱十年資料庫已填滿。
